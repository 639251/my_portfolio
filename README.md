# Mahi Soni — Professional Full-Stack Portfolio

Welcome to my portfolio! This is a modern, responsive, and visually appealing developer portfolio website. It has been built using a clean front-end structure served by a lightweight Node.js/Express backend, optimized for performance and easy deployment.

## 🚀 Live Demo & Preview
Deploy easily on platforms like Vercel with 1-click integration.

---

## ✨ Features

- **☯️ Interactive Theme Toggle**: Seamlessly switch between Light and Dark modes. The user's preference is saved in `localStorage` and persists across page reloads.
- **✨ Frosted Glassmorphism Design**: Modern, glass-like transparent sections (`backdrop-filter`) that look clean and premium on all screen sizes.
- **⌨️ Typewriter Effect**: Dynamic typing animation on the hero section highlighting core roles.
- **💼 Work Experience Timeline**: Structured timeline displaying internship details with an interactive **Certificate Lightbox Modal** (view and download features).
- **🛠️ Categorized Skills**: Grid display separating technical languages, frontend expertise, and productivity tools.
- **📱 Fully Responsive**: Custom CSS media queries designed to offer a flawless layout on mobile, tablet, and desktop screens.
- **🔝 Scroll Utilities**: Floating Scroll-to-Top button and smooth anchor scrolling.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (variables, transitions, keyframes, glassmorphism), JavaScript (ES6, custom typewriter, modal handlers)
- **Backend**: Node.js, Express.js (static assets routing)
- **Deployment**: Vercel configuration support (`vercel.json`)

## 💻 Running the Project Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v16 or higher) installed on your computer.

### Step 1: Clone the Repository
```bash
git clone https://github.com/639251/my_portfolio.git
cd my_portfolio
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Run the Server
Start the development server using:
```bash
npm run dev
```

### Step 4: Open in Browser
Navigate to:
```
http://localhost:3000
```

## 📦 Deployment on Vercel

This repository is pre-configured for Vercel Serverless deployments.

1. **Push your code to GitHub**.
2. **Import the repository** into your [Vercel Dashboard](https://vercel.com).
3. Vercel will automatically read the `vercel.json` config and deploy the app instantly under a free `.vercel.app` domain.
